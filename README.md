# AI Cuts Simple
Versão simples: HTML + CSS + JS no frontend e um único backend Python.
1. Publique a pasta server em um serviço com Docker.
2. Configure OPENAI_API_KEY (opcional), OPENAI_MODEL e PUBLIC_API_URL.
3. No script.js troque API_URL pela URL pública do backend.
Use apenas conteúdo que você tenha autorização para processar.
